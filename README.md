## Scarpet Scraps
small repository of scarpet scripts you can use

## How to install and use
1. Install the carpet mod.
2. Create a new world.
3. Open the folder which your worlds are in and find the world you created.
4. Find the folder inside of your world called "scripts".
5. Place the script inside of that folder.
6. Do `/script load script_name` with the name of the script file to load it. (this may require cheats to be enabled).

## Script specific instructions
### physgun.sc
Run the command `/physgun` to get a physgun. Right click to start grabbing an entity, left click to throw it, and right click again while holding an entity to drop it.
